# Enterprise Blueprint — Target Architecture for the ENX Foundry Environment

Target state for the Euronext InfoSec Assurance platform on **Microsoft
Foundry** (the product name since Ignite 2025; the kit's files still say
"Azure AI Foundry" — see the documentation delta at the end) as of
**2026-09-12**. It complements, and does not replace, `../infra/main.bicep`
and `../infra/README.md`: every decision below is either already
implemented by the kit (marked *kit*), implemented by the two new templates
in this folder (`landing-zone.bicep`, `azure-policy-assignments.bicep`), or
returned as a shared delta for the kit maintainer (D-EB*). Platform
invariants respected throughout: agents read-only
(`../governance/DATA_PROTECTION_GUARDRAILS.md` §2), verifier + human
approval before every write (`../governance/HUMAN_APPROVAL.md`), owner
review before every platform change (`../operations/CHANGE_MANAGEMENT.md`),
EU residency (`../infra/README.md` §Residency), light/chat/reasoning tiers
(`../governance/MODEL_ROUTING.md`). Owner: `{upn:francisco.gomes}`; users:
`sg-infosec-foundry-users` (five members, `../team/entra-groups.md`).

Status labels: **GA** / **preview** / **community** (non-Microsoft or
forum source) / **unknown** (could not be read in full). Every claim
carries its source; verify the URL before acting on a preview item.

## 5. Rollout order

1. Dev: deploy `main.bicep` (dev params) → `landing-zone.bicep` (`enableCmk=false`, `enablePrivateEndpoints=false`) → `azure-policy-assignments.bicep` (`effectMode=Audit`) → read compliance.
2. Prod: platform team creates hub rules + custom SKU policy; owner deploys `main.bicep` **with** D-EB3/D-EB4/D-EB8 (capability host, network injection, CMK, BYO stores) — these cannot be added later; then `landing-zone.bicep`, then policies with `Deny`.
3. `deploy.sh` (agents) on the Agents v2 runtime; A2A wiring; native Copilot publish for the six advisors; repeat RBAC for each published agent identity.
4. Enable Defender for AI (trial), Purview DSPM, Control Plane guardrail policies; export the first compliance view as the go-live evidence pack.
5. Quarterly: currency check (portal names, retirement schedule, EU region availability, preview → GA transitions), quota tier, policy compliance export.
